# 🧠 Cérebro da Vai de Taco

Memória permanente do projeto. **Toda sessão começa lendo `pendencias.md`** (e o resto só quando precisar).
Arquivos curtos, em tópicos, sempre com data. Compatível com Obsidian/Notion (é só markdown).

| Arquivo | O que guarda | Quando ler |
|---|---|---|
| [pendencias.md](pendencias.md) | O que está em aberto, quem depende de quem | **Sempre, no início** |
| [decisoes.md](decisoes.md) | Decisões tomadas e o porquê (não rediscutir) | Antes de propor algo que pode já ter sido decidido |
| [preferencias-do-dono.md](preferencias-do-dono.md) | Gostos, tom, o que ele aprovou/recusou | Antes de escrever ou desenhar |
| [acessos.md](acessos.md) | O que está conectado e como (sem segredos) | Antes de usar API/GitHub |
| [linha-do-tempo.md](linha-do-tempo.md) | Resumo de cada sessão | Quando precisar de contexto histórico |

## Regra de manutenção
Ao fim de cada sessão (ou quando o dono disser "salva"): atualizar `pendencias.md`, acrescentar decisões novas
em `decisoes.md`, registrar a sessão em `linha-do-tempo.md` e fazer commit + push.
Nunca gravar tokens, chaves ou senhas aqui.
